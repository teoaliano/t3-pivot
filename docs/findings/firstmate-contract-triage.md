## What matters most

1. **The reference clone is stale on the one number the map leans on.** The clone is 156
   commits behind upstream `c5f48e4c` (2026-09-29). VISION adopted a 9,000 word ceiling for
   the always-loaded contract on 2026-09-19 (`90cd351a`, #4873), and upstream then cut
   `AGENTS.md` from 11,473 to 6,845 words by moving situational sections into triggered
   skills (`49a218bb`, #5872). The map's "about 11,500 words" describes the clone.
2. **About 30% of the clone's `AGENTS.md` is Pivot judgment.** A rough line-by-line
   assignment gives bin 1 about 4,700 words, bin 2 about 1,500, bin 3 about 3,400, and bin
   4 about 1,800. Section 2 (state layout, 2,340 words) and section 3 (session start, 1,208)
   are almost all terminal and file machinery.
3. **Bin 2 is small and maps cleanly onto T3 events.** Its core is seven rules: the status
   grammar, the keyed decision fold, answerer-closes, the durable steer with an explicit
   acknowledgement, the durable wake queue acknowledged after handling, the teardown
   landed-work refusal, and recording the user's exact words when a decision closes.
4. **firstmate contradicts itself on decision closure, and still does upstream.** The fold
   drops every open decision when a ship or scout appends `done:` or `failed:`
   (`bin/fm-classify-lib.sh:422-423,701`, `334fa122`, #3753). The brief tells the worker
   that "a later `done:` or `working:` line never closes it" (`bin/fm-brief.sh:498`,
   `6c206edd`, #1842). The Pivot's decision model has to pick one.
5. **Record divergence disappears if decisions have one record.** firstmate stores a
   decision twice, as a keyed status line and as a held backlog task, and then needs a guard
   to catch the two disagreeing (`d3342dcf`, #2744, nine answered decisions kept coming back
   on 2026-08-06). With the backlog out of scope, a single decision entity avoids the guard.
6. **T3's merge lacks the head binding firstmate added after the fact, and T3's cleanup is
   safer than it looks.** T3's GitHub merge runs `gh pr merge <n> --<method>` with no live
   green check and no head binding
   (`apps/server/src/pullRequest/GitHubPullRequestCli.ts:1034-1036,2538-2546`). firstmate
   passes the verified head to the forge so a later push fails the merge
   (`bin/fm-pr-merge.sh:11-20`). T3's worktree cleanup refuses dirty trees and keeps the
   branch ref (`apps/server/src/storageCleanup.ts:223-362`), so firstmate's landed-work test
   only matters if Pivot teardown also deletes branches.
7. **T3 already covers several firstmate liveness fixes natively.** `session.status`,
   `latestTurn.state`, and `backgroundLiveness` (`packages/contracts/src/orchestration.ts:887-947`)
   replace the pane-hash stale detector, the per-harness busy hooks, and upstream's newest
   false-alarm fix for workers waiting on their own background shells (#5812).
8. **A handful of firstmate features fit no bin.** Quota-aware dispatch, the user
   preference files, and condition-to-action watches are neither out of scope in the map nor
   replaced by T3. They are listed at the end so a ticket can claim them.

## How the bins split

A rule about getting bytes into or out of a terminal, a pane, or a harness hook is bin 1. A
rule a script enforces so no agent has to remember it is bin 2. A rule an agent must read,
weigh, and apply is bin 3. Bin 4 follows the map's out-of-scope list.

firstmate states the same split in VISION: "Logic that can be exact lives in deterministic
scripts; work that requires understanding lives in an agent; the two never mix"
(`VISION.md:32-39`).

### 3.3 Budget

The raw carry is about 3,400 words from `AGENTS.md` and about 1,800 from skills. Dropping
script names, flags, and yolo and no-mistakes clauses should bring the always-loaded Pivot
contract to roughly 2,000 to 2,500 words, with `diagnostic-reasoning` and the stuck-worker
ladder loaded only when their trigger fires. Upstream's own trim (#5872) moved situational
contracts into triggered skills, the same pattern. In T3 the server could attach a skill's
text to the wake that triggers it instead of relying on the agent to load it.

local-only one 1,052, and a scout 916, before the Pivot fills intent and spec. About 200
words of each are the no-mistakes daemon rule and the Herdr gate, which drop.
