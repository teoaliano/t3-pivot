# Definition of done

This task delivers a ready branch. The project has no remote.

- Never push, never open a PR, and never merge. Work only on your branch. The Pivot lands
  it on the default branch once the user approves.
- The task is complete only when it is committed on your branch.
- Keep your branch a clean fast-forward of the current default branch. If the default
  branch has moved, rebase onto it. Landing is fast-forward only and refuses a diverged
  branch.
- When it is implemented and committed, report `done` naming your branch as ready, and
  stop.
