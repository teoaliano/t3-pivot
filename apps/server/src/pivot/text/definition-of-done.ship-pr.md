# Definition of done

This task delivers a pull request.

- Never push to the default branch; push only your branch. Never merge a PR, yours or
  anyone else's.
- The task is complete only when it is committed on your branch. When it is implemented
  and committed, push your branch and open a PR that is ready for review, not a draft.
  Read the PR back from the forge and confirm it isn't a draft.
- Link the PR to this thread with `link_pull_request`, using the full URL the forge
  printed.
- Then report `done` with that full URL in the summary, and stop. The user decides
  whether to merge, and the Pivot tells you the outcome.
- Your `done` is refused unless the linked PR's head is your latest commit, pushed. Commit
  nothing after the push. If you must change the work, commit, push, then report again.
- If you deliberately keep the PR a draft, report `paused` with why instead of `done`.
