# Tool choices

Type: grilling
Status: open
Blocked-by: 02

## Question

Which tools can a position switch on or off, in what groups, with what defaults per
outcome, and how is each enforced? Cover T3 MCP tool groups (browser preview, devices, PR
tools, thread tools), connected MCP servers, and provider built-ins where the research
shows they can be limited. Decide what the Settings editor says for a provider that can't
enforce a choice, and which tools are never removable (report_status, decisions).

From What stays fixed in the brief: the read-only project-checkout workspace turns off
file-editing tools where the provider allows (Claude's Edit and Write, Codex's read-only
sandbox). Fit that into the per-position tool choices.
