# The default positions that ship

Type: grilling
Status: open
Blocked-by: 03

## Question

Which positions does a fresh environment start with, and with what text? Options: two
neutral defaults (one per outcome, carrying today's scout and ship behaviour) or a starter
set drawn from the day-one list in the map's Notes. Decide names, instructions, outcome,
skills and tools for each, and what "Restore defaults" restores.

From What a position is: `TeammatePositions.resolve` needs a fallback when the Pivot passes
no position id or an id that has since been deleted. Decide what it falls back to.

From What stays fixed in the brief: every default position needs instructions, since they're
required. Decide which defaults that report back start in the project checkout, read-only,
rather than in their own worktree (Product manager and Researcher, for example).
