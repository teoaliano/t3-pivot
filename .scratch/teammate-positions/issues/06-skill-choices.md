# Skill choices

Type: grilling
Status: open
Blocked-by: 02

## Question

Where does the list of available skills come from, and how does a chosen skill reach a
teammate? Decide the source (which dirs, environment vs project), what happens when a
position names a skill the environment no longer has, and the fallback for providers that
cannot load skills (for example, inlining the skill text into the brief, or not supported).
